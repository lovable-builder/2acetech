# Grey-list check (art. 385(3) Civil Code) of the template clauses

Source: the 2acetech audit (`legal/OPEN-ITEMS.md` section 5), which read the 23 points of art. 385(3) KC in the Civil Code consolidated text Dz.U. 2026 poz. 795 **[A 2026-11-20]**.
Use this table as the seed of the grey-list table that `OPEN-ITEMS.md` must contain for every store (columns: clause, grey-list point checked, result). Re-check it when you add or change a clause,
and whenever the Civil Code changes (R-25). Section numbers are those of the fully featured Regulamin template (they are renumbered when features are off).
The black list of UOKiK practice and the UPNPR black list (art. 7) are separate checks: see `facts-vs-claims-truth-table.md` (T1-T11).
